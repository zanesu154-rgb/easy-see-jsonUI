# 5b 看 / 改布局与验收

本文记录 5b 当时的验收范围；玩家抽屉及缩略图已由 [5c](player-state-5c.md) 扩展。

基于 7b7791a 的脚本运行继续开发。本轮只整理页面、导航、状态摘要和工具入口，不实现 5c 的自动状态编辑与存档。

## 默认体验

| 区域 | 看 | 改 |
| --- | --- | --- |
| 顶栏 | 工程名、看 / 改、导入、导出、更多菜单；运行中可打开玩家状态 | 同左 |
| 左栏 | 脚本动作、可折叠的预览数据、单列界面缩略图 | 控件树、文件视图、搜索 |
| 中间 | 预览点击，隐藏选中框、面包屑和定义链接 | 选中、拖动、面包屑、定义定位 |
| 右栏 | 默认收起；可打开只读玩家摘要 | 属性、源码、数据、矩阵四页 |
| 底部 | 模拟/预设口径、脚本状态与时间控制、问题角标、控件预算 | 同左，另有动画 / 双屏入口；按需展开底部工具区 |

原版补齐、文件夹 / ZIP、字体和缓存集中在“…”的设置对话框。导出仍先走原有差异检查；工程导出、工程设置和追加依赖可从更多菜单进入。原有首页总览保留为显式入口；看模式导入后直接显示当前画面。

手写模拟 JSON 在“高级 › 手写模拟数据”里。纯资源包仍可使用状态示例、通道填表和预览数据预设；这些不是玩家存档。运行中的 OP、维度、背包格数和属性/标签/计分项数量为只读摘要。

## 状态边界

- editor-shell.js 只移动现有 DOM 节点并控制面板可见性，不修改文件 Map、历史、预设或模拟数据；原有控件 ID 与监听器继续使用。
- 看 / 改是工作区状态；现有内部 edit / preview 控制画布交互。默认两者对应看 / preview，切到改才允许选中、拖动。
- Tab 在画布和非交互区域切换；输入框、按钮、菜单、可编辑文本和打开的模态对话框保持焦点导航，Shift/Ctrl/Alt/Meta+Tab 不拦截。工具页支持方向键、Home/End；收起抽屉后焦点回到其入口。
- 切到改时暂停脚本时间并解除画布动画的外部时钟，以便编辑。Worker、待回复表单和输入 DOM 都保留；回到看时跟随原 tick，不自动续播。停止脚本仍恢复原预览数据和草稿，同时尊重用户当前的看 / 改选择。
- 每种模式分别记住缩放和左栏滚动位置；不把这些偏好写入资源包。
- 玩家状态自动编辑、state.json、命名玩家存档及采集包均未在本轮实现。

## 性能与诊断

- interfaceCards 新增 compact/lazy 选项；侧栏用 IntersectionObserver 排队，只解析接近滚动视口的卡片，按帧让出线程。隐藏或换代后停止旧任务；原首页保持原有渲染方式。
- 侧栏模型只在工程 / 导航 / 手动模拟数据变化后重建，脚本 tick 只更新当前高亮。未实现 5c“按玩家存档重绘全部缩略图”。
- 非活动矩阵页停止生成矩阵和三态对照；进入矩阵页时刷新。
- 脚本动作候选不变时保留原 select 选项，避免播放时持续重建下拉列表。
- 原版容器及 HUD 的 runtime info 提示均默认折叠；缺图警告和错误继续保留。状态栏角标排除折叠项，工具提示列出其数量。
- 运行错误在底部显示文件/行号并可打开源码；无源位置的超时消息显示为通知文本。

## 验收覆盖

- shell-regression：默认看、画布占比、看模式拖动不改源码、Tab 与输入/对话框规则、菜单、JSON 与源码未应用草稿、按需缩略图、Worker 与表单输入不重启、进入改暂停/返回不续播、只读状态抽屉、编辑拖动、独立缩放和窄屏。
- script-runtime-regression：保留默认看模式，独立包 Action/Modal/Message 回路、虚拟时钟、错误、超时与恢复；真实包 157 模块、三步引导、34 个按钮、秘境/开阳分页、任务领取 R → D 和管理员菜单。
- editing / browsing / simulation / preview 等旧回归显式进入改模式，以匹配它们检查编辑工具的目的。新默认体验由 shell 回归单独验证。
- 使用 2257 文件（206 个真实 UI 定义）的原版回归 ZIP 检查搜索；该 ZIP 有部分占位资源，不作为全量视觉一致性的证明。
