# Easy See JSON UI

轻量级 Minecraft 基岩版 JSON UI 本地编辑器，第一阶段原型。

运行：安装 Node.js 后执行 `npm start`，打开 http://localhost:5173 。测试：`npm test`。

支持导入 ZIP、mcpack、mcaddon、独立 UI JSON；控件树、基础 panel/label/image/button 静态预览、属性编辑、源码编辑、问题提示、撤销重做以及导出。文件不上传。无构建依赖，JSZip 随项目提供。

## 当前边界

- 预览不等同游戏效果；继承、变量、动态绑定、stack_panel 排列与特殊渲染器尚未实现。
- 属性编辑会将当前文件格式化为 JSON，移除注释；可通过撤销恢复。源码编辑支持 JSONC。
- 支持的尺寸为数字、px、百分比及百分比加减像素。其他表达式暂用默认尺寸。
- ZIP 导出保留未编辑文件字节内容；嵌套 mcpack 会展开为文件夹，导出 ZIP 不保留原嵌套容器形式。
- 不支持加密包；第一版限制单个输入 150 MB、单个解压文件 100 MB、嵌套深度 4、文件数 10000。解压总量限制仍需加强，不建议导入来源不明的大包。
- 贴图目前支持 PNG；没有导入的原版资源会提示缺失，不能据此认定游戏内有错。

## 第二阶段更新

已加入跨文件继承、基础变量与默认值解析、缺失依赖和循环继承诊断、stack_panel 横向及纵向排列。树和预览使用解析后的结构；当前实例修改写入覆盖值，继承子控件只读并提供定义文件跳转。脚本关联改为检查 title_text 条件，仍属于候选关联。

尚未支持完整表达式、bindings 执行、controls 修改指令及自动尺寸；重复命名空间不会模拟游戏资源包优先级。

## 表单模式与隔离修复

新增编辑/预览模式：当前实例数值偏移支持拖动（继承子控件、表达式偏移暂不支持）；预览可沿同文件中静态识别的 selection 数字条件与函数调用跳转。表单解析按函数边界分隔，按钮图标与文字组合显示；唯一匹配的自定义布局使用表单标题和正文上下文。多候选不自动选择。贴图与同名继承优先使用所属资源包，歧义不再随意取最后一项。

物品入口只识别同文件、调用附近的 typeId/itemName/nameTag 直接比较，显示为候选；不执行脚本。复杂回调、switch、动态参数、跨文件导入、完整 collection 绑定及原版字体/语言文件仍未完整支持，因此不保证与游戏完全一致。
