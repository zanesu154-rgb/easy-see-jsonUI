# Easy See JSON UI

轻量级 Minecraft 基岩版 JSON UI 本地编辑器。文件在浏览器内处理。

## 运行

安装 Node.js 后执行 `npm start`，打开 http://localhost:5173 。执行 `npm test` 运行检查。

## 功能

支持附加包、ZIP 和独立 UI JSON 导入，控件树、基础静态预览、属性和源码编辑、数值偏移拖动、撤销重做、模拟数据及导出。

## 原版预览资源

使用“加载原版 ZIP”或“原版文件夹”导入匹配游戏版本的资源。原版资源在独立预览层，参与贴图查找和 UI 继承，不作为项目界面入口，也不包含在导出中。右侧显示贴图来源；未找到时提示检查依赖、版本和路径。项目不内置或重新分发原版文件。

## 当前限制

预览不能完全替代游戏验证。完整动态绑定、控件集合、特殊渲染器、动画、自动尺寸和九宫格等仍待完善。属性编辑会格式化当前 JSON 并移除注释；未编辑文件保留原始字节。嵌套附加包导出为展开后的 ZIP。继承子控件暂为只读。多包冲突尚未提供可排序优先级。PNG/JPEG 可预览，TGA 等格式尚未支持。

脚本只做静态分析，不执行导入代码。动态参数、复杂调用或不明确的跳转不保证能识别。只读的原版文件仅用于预览。

第三方 JSZip 许可见 vendor 目录。
