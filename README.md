# Easy See JSON UI

轻量级 Minecraft 基岩版 JSON UI 本地编辑器。文件在浏览器内处理。

## 运行

安装 Node.js 后执行 `npm start`，打开 http://localhost:5173 。执行 `npm test` 运行检查。

## 功能

支持附加包、ZIP 和独立 UI JSON 导入，控件树、基础静态预览、属性和源码编辑、数值偏移拖动、撤销重做、模拟数据及导出。

文本支持命名字号及 `font_scale_factor`；`normal` 按中文约 9、常见字母和数字约 6 GUI 单位前进宽度、12 单位行高预览，再应用字体缩放和画布缩放。浏览器字体与游戏字形仍可能有差异。属性面板可以编辑命名字号、数字字号和字体缩放。

按钮默认仅显示 `default_control` 分支，预览模式随鼠标切换 `hover_control`、`pressed_control`；编辑模式可从工具栏强制显示悬停或按下状态。状态切换仅影响预览，不修改项目源码。

## 原版预览资源

使用“加载原版 ZIP”或“原版文件夹”导入匹配游戏版本的资源。原版资源在独立预览层，参与贴图查找和 UI 继承，不作为项目界面入口，也不包含在导出中。右侧显示贴图来源；未找到时提示检查依赖、版本和路径。项目不内置或重新分发原版文件。

## 当前限制

预览不能完全替代游戏验证。完整动态绑定、控件集合、特殊渲染器、动画及复杂的自动尺寸依赖仍待完善。已支持基础 `default`、`%c`、`%cm`、文本最大宽度、UV 裁切及数字 `nineslice_size`；父子尺寸相互依赖的布局仍可能与游戏不同。属性编辑与拖动采用 JSONC 局部修改，保留注释和原有格式；未编辑文件保留原始字节。嵌套附加包导出为展开后的 ZIP。继承子控件暂为只读。多包冲突尚未提供可排序优先级。PNG/JPEG 可预览，TGA 等格式尚未支持。

默认只做脚本静态分析。第五阶段 5a 提供主动启动的隔离脚本运行，支持范围与使用方法见下文；尚未模拟的世界 API 会记录提示。只读的原版文件仅用于预览。

第三方 JSZip 许可见 vendor 目录。


## 自动补齐官方预览资源

官方资源路径索引随项目发布（`src/official-index.js`），运行时无需请求 GitHub API。导入工程后按固定 Mojang/bedrock-samples 提交获取需要的 UI 和贴图，包括 `textures/items`、`textures/blocks`；先请求 raw.githubusercontent.com，失败后尝试 jsDelivr，并缓存下载结果。每轮最多下载 160 项，达到上限后可再次点击补齐以继续。也可点击“一键补齐原版资源”重试；网络失败时明确提示，仍保留手动 ZIP 和文件夹入口。只请求官方目录中存在的路径，不上传工程内容，不向资源源请求私有自定义文件名。参考提交不保证与任意游戏版本完全一致。

按原版源定义对比，未修改的原版顶层控件和原版继承子控件默认不列入树；勾选“显示未修改的原版控件”可查看。未获取原版基准时，不会凭名称猜测并隐藏控件。

## 表单集合预览

模拟数据可提供 formButtons 数组，每项包含 text、texture 和可选 button_id。固定 collection_index 及其子控件共享同一项图文数据；越界项隐藏。支持 form_buttons/button 基础工厂的只读预览实例，最多 500 项。预览点击显示 button_id 和从 0 开始的序号；仅在静态脚本关系明确时跳转。生成实例不写入导出的文件。

集合绑定支持使用 `binding_name_override` 将 `#form_button_texture` 写入图标的 `#texture` 属性；右侧绑定求值显示实际使用的集合贴图。

复杂 collection 类型、所有 factory 规则及游戏输入状态尚未实现。


## 界面诊断与模拟文件

问题检查使用当前场景的运行时求值：已成功计算的绑定不再提示缺少游戏数据，同控件的绑定错误合并显示，重复问题保留数量及定位路径。未显示的分支不创建 DOM，也不重复报告其预览能力提示；结构错误仍保留。

画布底部显示定义控件数、实际创建数、显示数、已创建但隐藏数、跳过创建的隐藏数。按钮状态分支保留在 DOM 中便于即时切换，其余不可见分支及后代会跳过。

在“模拟数据与预设”中点击“导入模拟数据 JSON”，可读取包含 `formTitle`、`formBody`、`formButtons`、`bindings` 等字段的对象，例如脚本导出的 `sim_qb.json`。模拟文件不加入项目或导出包。脚本表单列表去除显示用的 § 格式码；可静态读取的模板标题显示为 `MSQB:…|…`，未知变量不会被当成标题。导入脚本始终不执行，动态标题预览需提供具体模拟值。

通过 `modifications` 插入 HUD 等位置的定义列入“自定义控件”，悬停分组中的按钮可查看插入文件和根控件。追加独立 UI JSON 时，若仅存在一个明确的资源包 UI 目录，会放入该目录；多包时保留独立文件。

## 参考包回归

`npm test` 运行单元测试。支持 `--test-isolation=none` 的 Node 版本可使用 `node --test --test-isolation=none` 在单进程中查看所有用例。

提供了针对“武破方穹 V1.8.81.mcaddon”和配套 `server_form.json` 的浏览器回归脚本。先启动编辑器和带 `--remote-debugging-port=9222` 的 Chromium，然后执行：

```sh
npm run test:reference -- /path/to/reference.mcaddon /path/to/server_form.json
```

可追加第三个参数指定手动原版预览 ZIP。脚本需要支持内置 WebSocket 的 Node.js，使用构造的 34 按钮开阳页数据，检查真实导入、字号、寒意条、血条 UV、任务书悬停、模拟文件导入、隐藏分支计数及逐字节导出保真。附加包、玩家数据和官方贴图不随项目分发。


## 布局与源码草稿

百分比尺寸与子控件尺寸会迭代计算，并始终应用 `min_size` / `max_size`；最多计算 24 轮，未收敛时会明确提示循环依赖。横向和纵向堆叠支持 `fill` 分配剩余空间，嵌套子控件跟随最终位置。`ignored` 条件参与预览，`simulation.touch` 默认为 `false`，可设为 `true` 检查触屏分支，避免桌面和触屏控件重叠。

模板中的绑定对象、按钮映射及变量控件数组按实例作用域解析。无效的控件或绑定结构会显示诊断，允许修改源码或撤销恢复，不会因此中断整个预览。

未应用源码保留为各文件独立的内存草稿，切换文件、缩放和刷新预览不会丢失。应用前不会进入导出；如果属性编辑或依赖更新改变了文件基准，草稿仍保留并提示覆盖风险。页面刷新或替换整个项目会清除这些内存草稿。

## 松散补充贴图

“追加依赖包”也可以导入仅包含贴图的 ZIP。例如 `guji.zip` 的 `guji/paper_bg.png`，若项目只有一个明确资源包，且 UI 仅有一条匹配引用 `textures/ui/guji/paper_bg`，会导入到该资源包的对应目录。多包、多个匹配或包含独立 manifest 的包不推测归属；路径有歧义时保留原路径并提示。这样导出后仍具有正确的游戏目录。

参考回归脚本可使用第四个参数加入 `guji.zip`：

```sh
npm run test:reference -- /path/to/reference.mcaddon /path/to/server_form.json /path/to/vanilla-preview.zip /path/to/guji.zip
```

该组合额外检查普通表单只生成一个按钮实例、按钮位于纸张背景内、补充贴图的导出字节一致，以及源码草稿和异常结构的恢复。


## 文字排版与本地字体

label 默认左对齐，按钮文字默认居中；显式 `text_alignment` 保持有效。绘制与测量使用同一份分行结果，避免浏览器再次自动折行后撑开高度不足。默认字宽按游戏 GUI 单位近似：中文 9、常见字母与数字 6，空格及窄标点单独处理，再应用 `font_scale_factor`。这是一套近似度量，并非所有游戏版本的精确字体数据。

在“模拟数据与预设”中点击“导入预览字体”：

- 支持 `glyph_XX.png` 或包含此类文件的 ZIP。字体页为 16×16 字形网格，按非透明字形范围计算前进宽度；单色字形跟随文字颜色，彩色字形保留原色。未提供的字符使用近似度量和后备字体。
- 支持 TTF、OTF、WOFF、WOFF2，用于替换本地预览字形；前进宽度仍按游戏单位校准。
- 单独导入的预览字体仅用于当前浏览器预览，不上传、不额外加入项目导出；资源包原有的 font 文件照常保留。“重置字体”恢复默认近似度量。游戏的字体描述文件、特殊字距和所有字体效果尚未完整模拟。

字符串减法删除所有匹配片段，数字减法保持不变。成就弹窗可使用 `bindings["#text"]` 提供 `toast.` + 150 字符图标字段 + 50 字符背景字段 + 标题，路径字段用 `$` 补齐。`offset` 的 `@namespace.animation` 引用不会再报数组类型错误；可在“动画与双屏对照”中启用位移播放、暂停及拖动时间轴。

补充文字回归：

```sh
npm run test:text -- /path/to/reference.mcaddon /path/to/server_form.json /path/to/vanilla-preview.zip
```

覆盖补位弹窗、奖励文字单行、折行撑开高度、位图字体导入和重置、HUD 下自定义分组，以及异步资源状态竞争。

## 按钮命中与累加层级

预览模式只有按钮本身的矩形参与悬停、按下和点击。超出按钮范围的说明框、文字和图标只参与绘制，不会截获下方节点点击；在按钮外松开会取消触发，按住移回按钮可恢复按下状态。祖先的 `clips_children` 仍限制可见和命中区域。

控件保留逻辑父子关系，绘制层使用所有祖先与自身的 layer 之和。绘制元素处于同一层叠上下文，避免父级 CSS 的 z-index 把说明框压在后面节点下方。透明度、文字颜色、裁切及按钮状态可见性按逻辑树继承；编辑模式拖动父控件时，子控件随动且支持撤销，均不改变导出数据模型。

交互回归使用独立 Chromium 页，验证四种缩放比例、截图像素顺序、指针移出与释放、祖先裁切、编辑拖动，以及真实任务书 26 号说明框盖住 25 号按钮时仍点击到 25 号：

```sh
npm run test:interaction -- /path/to/reference.mcaddon /path/to/server_form.json
```


## 当前画布的集合按钮统计

集合统计包含当前界面中显式索引及工厂生成的集合按钮，显示和隐藏按绑定及按钮状态计算；被绑定隐藏、尚未绘制的按钮也算隐藏。绑定同一数据的子图标、文字不重复计数。另列“已建 / 未建”说明画布实际创建数量，缺数据提示按按钮计数。未激活、已整体裁剪的其他界面分支不计入当前集合；标准表单回退预览单独显示实际按钮数量。

## 第一阶段：保留原文的编辑与导出检查

属性值修改、清空覆盖值和拖动统一通过 `src/source-edit.js` 修改原始 JSONC。已有数组（如 offset、size、color）按变化的元素修改，保留数组里的注释、缩进、键顺序、BOM、CRLF 和尾逗号；新增属性使用本地 jsonc-parser。清空属性保留前后及值内部的注释。重复键导致编辑路径不明确时拒绝可视化修改，需先在源码中消除歧义。源码面板保留原文件换行约定；全文手动编辑仍以用户输入为准。撤销与重做恢复原文。

点击“检查差异并导出”会先显示相对导入原文的变更文件，展开可查看带行号的增删及上下文，确认后才下载；二进制文件显示字节数。差异很大的文件在计算超时后显示完整修改前后内容。尚未应用的源码草稿会明确列出，导出使用已应用版本，不隐式覆盖。追加依赖时，新导入或被替换文件以这次导入内容为基准；导出不会重置基准。原版预览资源、模拟数据和 `.easysee/` 工程文件不进入资源包。

当前文件源码区域提供“按生成文件保护当前文件”。文件开头的“由 … 生成”“自动生成”“Auto-generated / Generated by / Do not edit”等注释也会启用保护，显示注释中的生成器线索。保护同时覆盖属性、拖动和源码应用，预览、选择与导出照常可用。可手动取消保护；设置变更也支持撤销/重做。

“导出工程设置”单独下载 `easysee-project.json`；重新导入项目后可通过“导入工程设置”恢复标记，也可把该设置放进项目 ZIP 的 `.easysee/project.json`。此设置保存手动保护及解除保护的覆盖值，自动识别的注释无需额外记录。设置按完整导入路径匹配；不记录预览生成实例。页面刷新不自动保存工作区；可导出编辑器工程一起保存已应用源码、设置和预设，或分别导出 JSON。未应用的源码草稿需先应用。示例：

```json
{
  "version": 1,
  "generatedFiles": {
    "MS_RP/ui/ms_questbook.json": true
  }
}
```

第一阶段浏览器回归：

```sh
npm run test:editing -- /path/to/reference.mcaddon
```

覆盖真实 hud_screen.json 单数值修改、导出只变化一行、注释保留、BOM/CRLF、拖动、撤销重做、源码草稿、生成文件保护、工程设置往返，以及工程设置不进入资源包。

## 第二阶段：按界面浏览和定位

默认“界面视图”按 HUD、表单、容器与物品栏、聊天等类别组织。跨文件挂载的表单定义归入表单类别；“文件视图”保留原有文件、根控件与引用模板浏览方式。导入新项目后先显示界面总览，可点击卡片打开界面或表单分支。卡片给出聚焦内容的布局缩略图、定义控件数和当前示例数据下的问题类别数；缩略图用于识别布局，未复刻完整 UV、九宫格、字体和动画效果，以正式画布为准。

表单分支读取各控件自身的标题可见条件，支持标题绑定别名，区分包含、相等和其余分支。点击分支自动填写可满足条件的标题并选中挂载实例；复杂条件无法自动推断时提示手动填写 `formTitle`，不会执行脚本或猜测条件含义。控件路径区显示挂载文件，提供定义文件跳转、返回挂载界面以及关联脚本文件和行号。脚本查看器只读，并定位到表单创建位置。

通过“应用模拟数据”或导入 JSON 提供具体 `formTitle` 后，对应表单分支会记住该数据。切换其他分支后，从分支入口或 `◇ MSQB:…|…` 脚本入口返回时会恢复这组数据；尚无具体数据的动态标题使用静态字符串部分加“示例”占位。这里只保存当前会话内的每分支最近一组数据，刷新或替换项目会清除；第三阶段已增加多组命名预设与 `.easysee/presets.json` 的工程保存，见下节。

编辑模式按实际叠放顺序点选控件，同一点再次点击可向下逐层切换，面包屑每一级均可选中；拖动时，若已选控件自身也在指针下，优先移动已选控件及其子树，否则移动命中的控件。预览模式仍只允许按钮自身矩形触发交互，说明框不会抢占按钮点击。搜索支持控件名、贴图路径、绑定名、表达式前缀和文件路径，也包含当前画布求值后的贴图与文字；结果展示完整控件路径，最多显示前 100 项。

体验修复：新增 offset 会参考原文件已有的单行数组样式；应用源码后显示“已应用”，语法错误直接显示行列位置；解析失败时属性栏明确提示当前文件解析失败。

```sh

```

## 原版搜索性能与浏览回归

搜索索引按项目／原版分别缓存：未勾选“显示未修改的原版控件”时，在读取文件前跳过原版文件；勾选时才建立原版部分。两部分都按 JSONC 源码中的控件定义建索引，不递归展开所有继承模板；已打开画布再补充当前实例求值后的文字、贴图和生成控件，避免原版库复杂继承把索引成倍放大。继承模板的静态匹配会定位到定义文件，当前活动实例的匹配可以定位到实例。

左侧搜索与浏览工具固定在滚动区域顶部。无界面入口信号的继承面板别名留在文件视图的引用模板中；已通过表单分支挂载的 screen 定义不再重复列作界面，仍可从分支打开定义。缺省命名空间优先使用已有原版元数据（如 `chat`），未知时显示文件名，避免空白前缀。

分支卡片的控件数及问题类别只统计各自子树，控件数包含被绑定隐藏的子控件；普通表单、武道天书、任务书和星空图不再重复显示整个 `long_form` 总数。没有真实数据时，脚本表单的动态说明使用“示例”占位，不显示 `${...}` 源码；用户手动填写的模拟数据保持原样。界面总览不显示旧控件属性，返回画布后恢复选择。

完整原版库浏览器回归：

```sh
npm run test:browsing -- /path/to/reference.mcaddon /path/to/server_form.json /path/to/full-vanilla.zip
```

此脚本要求至少 2000 个资源文件、150 个 UI JSON，测量单字符首次搜索、连续搜索和原版开关切换，并对搜索设置超时保护。覆盖工具栏固定、模板和重复入口过滤、命名空间、分支控件数、说明占位、首页属性栏以及资源文件不变。开发验证使用 2257 文件的回归包：包含固定参考版本的全部 206 个原版 UI，复用已有预览贴图，其余贴图为占位图；不用于验证贴图还原，不随仓库分发。可直接传入实际游戏版本的完整原版 ZIP 复测。


## 第三阶段：容器、模拟字段、预设与预算

界面视图增加“容器”：从 `variables` 及 `modifications` 对变量表的插入规则发现普通箱子、灵海戒和储物戒分支。`requires` 使用受限表达式求值器，按原有顺序覆盖变量，再展开 `$screen_content`。箱子标题使用独立的 `containerTitle`，完整保留 § 码；“容器布局”选择桌面／手机时同步 `touch`、`pocketEdition`、`pocketScreen`。后面的手机规则可以覆盖桌面规则。`§r§1§r` 只改显示标题，不替换箱子内容。

原版 ZIP 和自动补齐都会保留原版 UI 基础文档，自定义同名定义仍优先，贴图继续按资源覆盖排除重复。预览使用同命名空间的原版根控件作为覆盖基准；缺少原版时仍可解析自定义内容入口，但普通箱子、背包和通用控件需要匹配版本的原版依赖。`grid` 按 `grid_dimensions` 展开格子，支持 `container_items`，可在模拟 JSON 中提供 `containerItems: [{"name":"物品名","texture":"textures/items/diamond","count":12}]`。空格子不会因没填物品数据而消失。玩家背包、快捷栏可分别提供 `inventoryItems`、`hotbarItems`。物品以二维贴图和数量预览，未实现游戏物品三维渲染、拖动物品、实际存储或游戏脚本。生成格子只读，不写入源文件；每个网格预览上限 1024 格。文件视图按实际 UI JSON 补齐入口，包含仅有模板或 modifications 的文件。

容器默认按未锁定、未选中、无手柄提示和零安全区留白预览，显式 `simulation.bindings` 可覆盖这些默认值。未写尺寸的图像与按钮使用父控件大小，避免 18×18 格子被默认的 100×30 撑大。原版容器的信息级运行时提示默认折叠；自定义绑定提示、缺图警告和语法错误保留在主列表。背景 `ring_gui.png` 自带黄色标题条，编辑器不改动该贴图。

“模拟数据与预设 → 按通道格式填表”根据截取、减法、前缀比较及绑定别名推断字段。首领血条识别阶段枚举、48 格二进制填充和后续文字；滑条松开后自动生成字符串并更新预览。弹窗识别两段固定长度贴图路径并自动补 `$`。超长固定字段会拒绝应用。在界面视图选择事件工厂（例如 `hud · test_factory`）时，会沿 `factory.control_ids` 引用识别模板格式，并显示只读事件样本（最多 8 个），无需切换文件视图；样本不代表实际游戏事件的频率或同时实例数。未知格式保留手填 JSON，不执行导入脚本，也不声称能推断任意表达式。

每个界面可保存多组命名预设；“导入模拟数据 JSON”既可读取脚本导出的普通模拟 JSON（自动以文件名保存为预设），也可合并编辑器的预设文件。预设包含所属界面和完整模拟数据，可跨界面加载；找不到对应文件时提示先导入工程。支持最多 100 组预设、每组最多 500 个表单按钮、各物品集合最多 2048 项。

“导出编辑器工程”下载含资源文件、`.easysee/project.json` 和 `.easysee/presets.json` 的 ZIP，重新导入可以恢复保护标记和预设。也可以只导出 `easysee-presets.json`。常规“检查差异并导出”继续排除所有 `.easysee/` 文件、原版预览资源和模拟数据；项目导出只保存已应用源码，草稿需先应用。编辑器不会自动保存到磁盘，刷新前需下载工程或预设 JSON。

“状态矩阵与按钮对照”从拼贴图表达式和已有资源提取各字符位置的可选值，只在单字符变化相连的命名组内组合，避免 `tab_on` 和 `tab_P0/P1` 混合生成 `Pn`、`o0` 等虚构路径；列出组合并标红缺图／歧义路径；任务书节点可得到 3×4 的 12 种组合。超过 128 个组合时只列出现有资源；完全没有资源名时提示加载依赖，不把无法枚举当作检查通过。此推断不能发现资源与表达式中从未出现的整类状态。可选中一个按钮，并排查看默认、悬停和按下；对照不改变主画布状态或源码。

创建预算统计已解析、生成的候选控件，包含绑定隐藏分支，排除已确定 `ignored` 的子树。表单同时列出各分支，按定义来源拆成本包／原版／合计；黄色、红色只按本包超过 1000／3000 判断。生成模板中的子控件保留各自来源，继承的原版内部结构不会变成本包预算。该数不是优化裁剪后实际绘制的 DOM 数；缺少继承依赖、达到预览上限或未知运行时条件时不能作为游戏中的精确实测值。

## 第四阶段：动画、设备对照、字体与缓存

在“动画与双屏对照”打开“启用动画预览”。时间轴支持播放、暂停、回到开头及逐帧拖动（0.01 秒）；播放时最高约 30 帧更新已有控件，不反复创建整棵 DOM。动画启用期间暂停画布拖动，关闭后恢复；显式修改属性和源码仍按原有编辑流程处理。支持 `offset`、`alpha`、`wait`，`next` 串联及循环，并支持常见线性、sine、quad、cubic、quart、expo 缓动；未识别的缓动按线性处理。带 `play_event` 的入口需从动画事件下拉明确选择。仅预览动画，不发送游戏事件、执行脚本或删除源控件；`destroy_at_end` 在结束帧隐藏对应样本。大小、翻页、UV、颜色动画及完整游戏动画生命周期尚未实现，无法播放的类型会显示提示。

弹窗可直接选“hud · test_factory”，填入模拟弹窗后拖时间轴：0–1 秒滑入、1–5 秒停留、5–6 秒滑出。任务书的 `pulse / pulse_back` 链按透明度循环预览。切换界面会暂停并归零；同一界面重新求值时保留当前帧。时间轴默认关闭，因此导入后的静态浏览和源码行为不变。

“并排对照电脑与手机”共享已应用的模拟数据、字体和时间轴，分别按电脑 1920×1080／GUI 3×（640×360 单位）与手机 1280×720／GUI 最大 4×（320×180 单位）计算布局；手机启用 touch、pocketEdition、pocketScreen，容器分别展开桌面和 `_m` 模板。双屏只读，不改动主预览的设备设置。青色虚线是可调 0–10% 的安全区参考线，不修改游戏安全区设置；红框统计控件矩形越过屏幕边界的情况（文字矩形也计入，不等同于文字像素越界）。两块预览分别保留原始比例，不能代替具体设备和游戏版本的实测。

“字体与原版缓存”提供英数墨迹拉齐、内置 ASCII 像素字体和包内字形选择。拉齐只改变字形外观，保留数字约 6、中文约 9 单位的排版字格。内置像素字体覆盖常用英数字，其他字符使用回退字体；包内支持 `font/glyph_XX.png` 和 `font/default8.png`，本包同名字形页优先，支持 Unicode 私用区图标字。也可继续导入 TTF／OTF／WOFF 或字体 ZIP。缺失字形保留回退，切换字体会重新计算布局，但不会改源码。字体描述 JSON 和游戏全部字距特效仍未实现。

自动补齐使用随项目固定的原版文件索引，不调用 GitHub API；下载的 UI、物品、方块及索引可用的字体页保存到 IndexedDB，键包含完整参考版本与资源路径。再次打开并补齐相同依赖会优先读取缓存，已有缓存可离线使用；没有缓存的资源仍需网络。缓存按资源需求读取，不把整个原版库自动装入当前工程。可查看本版本文件数和体积，或清除本版本缓存；清除不会移除当前工程正在使用的预览资源，也不会清除其他版本。浏览器不允许持久存储或写满时回退为正常下载。当前 Mojang 参考索引不含 font 页，游戏字形可从本地原版 ZIP／资源包导入。

预算示例：参考任务书所有表单分支合计 3383，拆为本包 764／原版 2619；任务书分支为本包 367，按本包口径不再触发红色。81 格戒指为本包 23／原版 11429。数值受资源版本、模拟集合长度、忽略条件及预览上限影响，仍是静态创建估算。原版触屏拆分堆叠及方向进度覆盖层也默认隐藏，显式模拟绑定可覆盖默认值。

```sh
npm run test:preview -- /path/to/reference.mcaddon /path/to/server_form.json /path/to/full-vanilla.zip
```

## 未填模拟数据时的预览

打开任务书分支仅会填入匹配分流条件的标题，不会自动执行脚本或生成真实按钮数据。尚未提供对应 `formButtons` 项时，编辑模式保留有序号的中性占位以便选择、拖动，预览模式隐藏这些缺数据的按钮；不会继续展开其动态贴图，也不把 `n_`、`g_` 等未拼接完成的路径当成缺图。导入 `sim_qb.json` 或加载已保存的预设后，会重新正常渲染；此时真正缺失的完整贴图路径仍会报告。

## 第五阶段 5a：运行附加包脚本

导入含行为包脚本和 JSON UI 的附加包，按需追加依赖和原版资源。左栏出现「脚本运行 · 5a」后：

1. 选行为包入口，点击「启动脚本」。仅运行 manifest 声明的入口及其依赖；导入、搜索和浏览文件不会执行脚本。
2. 在动作列表选择物品使用、玩家出生、维度切换或脚本事件，点击「触发动作」。物品动作是基于脚本引用的候选项；是否响应由脚本实际分支决定。
3. 直接点击游戏画布上的按钮。脚本收到真实的选择序号后继续运行；关闭表单返回 canceled。未识别到自定义布局的普通表单及输入/确认表单使用标准控件近似展示。
4. 默认暂停时间，可单步、快进 1 秒或以 1/2/4/10 倍播放；每秒 20 tick。脚本定时器、Date.now 和画布动画共用虚拟时间。任务书等脚本自己的状态缓存也随此时钟过期。
5. 「未模拟 API / 运行信息」按调用次数汇总缺口；「HUD / 聊天输出」保留当前输出。脚本异常也显示在底部，可点击定位包内文件和行号。

**武破方穹验证路径：** 右键「古旧的羊皮卷」，按脚本完成三步引导，再右键打开任务书；可以切换秘境、开阳小页。需要调整境界时，先关闭当前表单，再右键「管理员令牌」进入包自带的武道修改器。领取回归使用包自带的 `ms:q_kill 1` 测试事件、推进 1 秒后，打开任务第一页领取「初识」；按钮由 R 变 D，奖励写入模拟背包。此过程不手填 formButtons。秘境世界探索本身不在网页中运行。

启动使用全新模拟玩家（OP、空背包和默认状态），并不读取游戏存档。「停止」恢复启动前的界面、模拟数据和未应用草稿；「重置并重启」丢弃这次脚本状态。自动状态面板、命名存档预设及真实状态采集属于后续 5c–5e，本轮没有实现。

运行位置是由不含 allow-same-origin 的 sandbox iframe 创建的 Worker，CSP 禁止联网和外部脚本加载；运行器没有宿主 require、文件或存储权限。超时会停止 Worker，页面可继续使用。编译器随项目分发，只在启动时加载，不通过 CDN 执行包代码。它不是完整的 Bedrock 引擎：实体、方块、结构、粒子、声音和多数命令尚未模拟；已实现的数据/表单接口与明确的空结果见 [5a 实现说明](docs/script-runtime-5a.md)。脚本依赖未支持的返回类型或外部模块时仍可能无法继续，此时需要根据诊断补齐 API，不能把预览视为游戏正确性证明。

执行 `npm run test:scripts` 运行独立包浏览器回归；可追加附加包、依赖 JSON、原版 ZIP 三个路径来验证真实包。需先运行本地服务，并启动 CDP 端口 9222 的 Chromium。
